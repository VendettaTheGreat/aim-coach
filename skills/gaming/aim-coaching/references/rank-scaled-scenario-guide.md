## Applying the difficulty scale

- Select the sheet tab by the scenario archetype and observed coaching issue, not by a required Voltaic rank. A player's Smoothness & Control variation can be at a different tier from Reactive Tracking or Keyboard Strafes.
- Start with the easiest appropriate variation that still exercises the target skill. Move up within that archetype when the current version no longer challenges the intended control or its purpose has been served and performance is stable. Increase one demand at a time.
- Use scores, VODs, coach notes, or the player's report that a drill feels controlled/visually easy as evidence for progression. Do not assign a global user rank from one weakness.
- Size, target path, player movement, and speed remain separate dimensions. Do not use a higher sheet tier to compensate for mismatched task geometry.
- The official scenario interface remains the source of truth for current title, live availability, description, and variant settings. Do not trust a sheet link or spelling alone.

## Current diagonal-tracking note

The sheet's difficulty tabs provide smoothness/control examples, but VAI angles are a separate geometry axis. VAI numbers denote target movement angle in degrees, so select an angle that resembles the gameplay example or use a deliberate multi-angle sample; do not repeat one VAI number as if it generalized to all diagonals. User-provided rule: prefer Invincible variants for longer uninterrupted tracking time when the official variant matches the task. PGTI may involve jumper targets; treat it as jumping-target tracking, not a continuous diagonal line, unless the exact scenario proves otherwise.
